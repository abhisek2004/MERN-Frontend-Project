## 🚀 Getting Started

Clone this repository:

```bash
git clone https://github.com/abhisek2004/MERN-Frontend-Project.git
```

Navigate into the project:

```bash
cd MERN-Frontend-Project
```

Open the required project folder and run it using the appropriate development setup.

For simple HTML/CSS/JavaScript projects, you can open the `index.html` file directly in your browser or use **Live Server** in VS Code.
